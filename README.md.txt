Student Performance Analysis

About the Project

This is a SQL project I created to practice working with MySQL. The goal was to build a simple database for student information, university courses, and grades, and then use SQL queries to analyze the results.

Database Tables

The database has three tables:

* Students: Contains student names, ages, and majors.
* Courses: Contains course names and credits.
* Grades: Stores students’ scores for different courses.

I used primary keys and foreign keys to connect the tables.

What I Practiced

While working on this project, I practiced:

* Creating tables and inserting data
* Connecting tables using JOIN
* Calculating average and highest scores with AVG() and MAX()
* Grouping results using GROUP BY
* Filtering grouped results with HAVING
* Sorting results with ORDER BY
* Ranking students using RANK()
* Categorizing scores using CASE WHEN

Tools

* MySQL
* MySQL Workbench

What I Learned

This project helped me understand how relational databases work and how SQL can be used to answer questions about data, such as which students have the highest averages and which courses have the highest scores.

The database uses sample data created for practice.
